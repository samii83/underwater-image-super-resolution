# Experiment Outputs

This directory stores generated artifacts, test predictions, and visual comparisons.

## Subdirectories
- `outputs/inference/`: Generated super-resolved images produced by `inference.py` or the Gradio app.
- `outputs/evaluation/`: Benchmarking predictions generated during test set evaluation with `evaluate.py`.

> [!NOTE]
> All generated output image files are ignored by Git via `.gitignore`.
