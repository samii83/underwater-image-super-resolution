# Sample Images

This directory holds sample underwater images used for inference demonstrations and quick qualitative checks.

## Contents
- `underwater_sample.png`: Synthetic 128x128 RGB underwater test image with oceanic blue-green gradient.
- Add additional sample images here (`.png`, `.jpg`) to run quick inference tests:
  ```bash
  python -m underwater_sr.inference --input sample_images/underwater_sample.png --scale 4
  ```
